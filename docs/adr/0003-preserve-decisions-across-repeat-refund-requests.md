# Preserve decisions when learners request a refund again

A declined learner may submit a new Refund Request with an updated description. The earlier request retains its decision, explanation, decision maker, and timestamp instead of being reopened or overwritten. This preserves the context of each review while allowing the learner to present new circumstances.

Each request's first saved decision is final, including when reviewers act concurrently. Approval prevents further requests for that purchase; Pending or Failed Refunds are resolved through payment handling on the existing approval. A later purchase is separate.
